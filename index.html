AquaMonitor IIoT

Monitoreo inteligente del nivel de agua

AquaMonitor IIoT es un proyecto academico de ingenieria mecatronica destinado al monitoreo del nivel de agua en un tinaco.

El sistema utiliza un ESP32 y un sensor ultrasonico A02YYUW para obtener mediciones que se transmiten mediante MQTT y se almacenan en una base de datos MariaDB.

Integracion con Google Drive

El proyecto utiliza rclone y Google Drive para realizar respaldos de las mediciones almacenadas en la base de datos.

La integracion esta destinada al uso personal del propietario del proyecto.
